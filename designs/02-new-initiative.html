What happens next

  1. You choose a compliance profile and connect a repository.
  2. Platform verifies the repo and applies branch protection plus the required sdlc/gate check.
  3. You assign roles. The platform checks separation of duties up front.
  4. G0 is signed by you (Product Owner) and QRA. Only then does the Product Agent start drafting requirements.

Why the repo comes first

Git is the source of truth for requirements, ADRs, code and tests. Evidence records bind to commit SHAs and artifact hashes, so the platform cannot produce evidence until a verified repo exists.

⚖
If anyone changes branch protection outside the platform, a deviation is recorded automatically.
